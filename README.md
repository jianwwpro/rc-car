# RC-Car —— RC 攀爬车声音模拟与车身姿态系统

基于 **嘉立创·实战派 ESP32-S3**（LCKFB-SZPI-ESP32-S3-VA）的 RC 攀爬车声音模拟与姿态显示项目。

通过 RC 接收机的 PWM 通道控制引擎声、倒车声、警笛/救护/消防音效，并在 2.0 寸 ST7789 屏上用 LVGL 绘制飞机式姿态地平仪与坡度显示。

---

## 一、硬件平台

| 项目 | 型号 / 参数 |
|------|-------------|
| 主控 | 嘉立创·实战派 ESP32-S3（LCKFB-SZPI-ESP32-S3-VA） |
| 模组 | ESP32-S3-WROOM-1-N16R8（16MB Flash + 8MB OPI PSRAM） |
| 屏幕 | 2.0 寸 IPS 320×240，ST7789（4 线 SPI，RGB565） |
| 姿态传感器 | QMI8658（I2C 地址 `0x6A`） |
| 音频编解码 | ES8311（I2C 地址 `0x18`，I2S 输出到板载功放） |
| IO 扩展 | PCA9557（I2C 地址 `0x19`，控制 LCD_CS / PA_EN / DVP_PWDN） |
| 开发框架 | PlatformIO + Arduino（ESP32-S3） |

## 二、技术架构

### 2.1 软件框架

```text
┌─────────────────────────────────────────────────────────┐
│                     PlatformIO + Arduino                 │
│                                                         │
│  FreeRTOS 双核任务                                       │
│   ├── audioTask  (Core 0)  合成音频 → I2S → ES8311 → 喇叭 │
│   └── lvglTask   (Core 1)  LVGL 刷新 → SPI → ST7789 屏幕  │
│                                                         │
│  loop() 主循环（Core 1 空闲）                             │
│   ├── readReceiver()  读取接收机 PWM                      │
│   └── updateUi()      更新地平仪 / 坡度 / 状态文字         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 数据流

```text
RC 接收机 PWM（4 通道）
   │  GPIO 中断捕获脉宽（micros）
   ▼
readReceiver()
   ├── 油门通道 → g_driveState（怠速/前进/倒车）+ g_throttle01
   ├── 警笛/救护/消防 → g_policeOn / g_ambulanceOn / g_fireOn
   ▼
audioTask → synthFill() 实时合成 PCM
   │  I2S（16000Hz / 16bit / 立体声 / MCLK×384）
   ▼
ES8311 → 板载功放 → 喇叭

QMI8658（I2C）→ 姿态角（俯仰/横滚/坡度）
   ▼
lvglTask → LVGL canvas 绘制地平仪 + 底部状态文字
   ▼
ST7789（SPI，RGB565，字节交换）
```

### 2.3 关键配置

- LVGL 8.3.11，`LV_COLOR_DEPTH=16`，`LV_COLOR_16_SWAP=1`（匹配 ST7789 字节序）。
- LVGL 显示驱动 `lv_disp_drv_t` 使用全局静态变量（`lv_disp_drv_register` 仅保存指针）。
- 刷新回调通过 `esp_lcd_panel_io_register_event_callbacks` 的 `on_color_trans_done` 通知 LVGL，等 SPI DMA 传输完成后再刷下一帧（避免黑条纹/撕裂）。
- 地平仪画布缓冲使用内部 RAM 分配。

## 三、功能介绍

### 3.1 声音控制（接收机通道）

| 通道 | 功能 | 行为 |
|------|------|------|
| CH1 | 油门（比例） | 中位=静音；前推=引擎声（频率随油门升高）；拉回=倒车滴滴声 |
| CH2 | 警笛开关 | 高电平开、低电平关（600~1200Hz 扫描音） |
| CH3 | 救护开关 | 高电平开、低电平关（700/950Hz 交替音） |
| CH4 | 消防开关 | 高电平开、低电平关（400/500Hz 低频交替音） |

- **上电默认静音**：油门中位时不发声。
- 引擎声跟随油门，无独立开关通道。
- 四个通道相互独立，可同时发声（软件混音）。

> 当前声音由程序实时合成（正弦/锯齿波合成的占位音效），后续可替换为真实音频文件播放（I2S 通路已就绪）。

### 3.2 屏幕显示（LVGL 姿态地平仪）

- 飞机式姿态地平仪铺满屏幕上方（320×216），随 QMI8658 俯仰/横滚实时旋转与偏移。
- 底部一行缩略状态文字：
  - `SLP`：坡度百分比
  - `ENG`：引擎是否在响（前进/倒车时 ON，怠速 OFF）
  - `POL` / `AMB` / `FIR`：警笛 / 救护 / 消防开关状态

## 四、接线介绍

### 4.1 接收机 → 板子（GH1.25 扩展接口）

接收机 4 个通道的信号线分别接到对应 GPIO，所有通道共地，供电接一次即可。

```text
RC 接收机（4 通道）         信号线             板子引脚
─────────────────────────────────────────────────────────────
CH1 油门    [S 信号] ──────────────────────────►  GPIO13
            [+ 正极] ─┐
            [- 负极] ─┼─── 共地 ───────────────►  GND
                       │
                       └──── 5V 供电 ──────────►  5V   (接收机取电)

CH2 警笛    [S 信号] ──────────────────────────►  GPIO14
            [- 负极] ────── 共地 ──────────────►  GND

CH3 救护    [S 信号] ──────────────────────────►  GPIO23
            [- 负极] ────── 共地 ──────────────►  GND

CH4 消防    [S 信号] ──────────────────────────►  GPIO24
            [- 负极] ────── 共地 ──────────────►  GND
─────────────────────────────────────────────────────────────
```

| 功能 | 油门 | 警笛 | 救护 | 消防 | 地 | 5V |
|------|------|------|------|------|----|----|
| 板子 | GPIO13 | GPIO14 | GPIO23 | GPIO24 | GND | 5V |

**接线规则：**

1. **信号线**：接收机每个通道的 `S` 脚接到上表对应 GPIO。
2. **共地**：接收机 `-` 与板子 `GND` 必须相连；接收机各通道 `-` 内部并联，只需引一根地线即可。
3. **供电**：若接收机无独立供电，从任意通道 `+` 接 5V、`-` 接 GND 到板子；若接收机已由电调 BEC/电池供电，则**只接信号线 + 共地，不要再接 5V**（避免电源打架）。

### 4.2 板载外设（无需外部接线）

屏幕（ST7789）、姿态传感器（QMI8658）、音频（ES8311 + 功放 + 喇叭）均为板载，无需额外接线。烧录与串口调试走板载 USB Type-C（CH340）。

## 五、编译与烧录

```bash
cd RC_Audio

# 编译
pio run

# 烧录（需串口权限，参考下方说明）
pio run -t upload

# 串口监视
pio device monitor
```

**串口权限**（Linux）：将当前用户加入 `uucp`（或 `dialout`）组后重新登录：

```bash
sudo usermod -aG uucp $USER
```
